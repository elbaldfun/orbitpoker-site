What you need

  • One iPhone running Orbit Poker as the host
  • A modern browser on each guest phone (guests with an iPhone can also join from the Orbit Poker app)
  • All devices connected to the same Wi-Fi network or the host’s Personal Hotspot
  • Players age 18 or older

Orbit Poker uses play chips for scoring only. It does not support real-money betting, purchases, cash-out, prizes, or chip transfers.

Start a table

  1. Open Orbit Poker and create a table.
  2. Choose the blinds, starting chips, seats, and action timer.
  3. Make sure every guest is on the same local network.
  4. Show the seating QR code. Guests scan it with the system camera and join in their browser.
  5. Seat at least two players, arrange the seat order, and start the first hand.

The next hand doesn’t start

A hand needs at least two seated players who have chips and aren’t sitting out. Between hands, the host screen shows why the next hand is waiting and offers a fix:

  • Out of chips: tap Top up, or approve the player’s rebuy request.
  • Sitting out: wait for the player to come back, or ask them to tap Sit back in.
  • Not enough players: show the seating QR code so someone else can join.

While the countdown to the next hand is running, the host can tap Hold to pause dealing, or Deal now to start immediately.

A guest cannot open the QR link

  • Confirm that the guest and host are on the same Wi-Fi or Personal Hotspot.
  • On the host iPhone, open Settings → Orbit Poker and allow Local Network access.
  • Avoid guest Wi-Fi networks that isolate devices from each other.
  • If the host changed networks, use the newly generated QR code.
  • Keep Orbit Poker in the foreground on the host device.

The host locked the phone or switched apps

The table pauses when the host app becomes inactive. Return to Orbit Poker and wait for guests to reconnect, then tap Continue. Guests should keep the browser page open. For the most reliable game, use a spare iPhone as the host.

Recover an interrupted table

If Orbit Poker finds an unfinished table after relaunch, choose Recover Previous Table. The table opens paused. Wait for the players to reconnect before continuing. Do not choose Discard unless you intend to permanently remove the current table snapshot.

A guest lost their seat

Rescan the current seating QR code and enter the same nickname. If that seat is offline, the host can approve the request to reclaim it. If the old page is still online, close it first or use a different nickname.

Delete table data

On the host iPhone, end and clear the table. Orbit Poker deletes the current local table snapshot. Guests can remove a stored seat credential by clearing site data for the host’s local address in their browser.

Report a problem

Email elbald.fun@gmail.com with:

  • host iPhone model and iOS version;
  • guest device and browser version;
  • Wi-Fi or Personal Hotspot;
  • what screen and hand number you were on;
  • exact steps, error text, and whether restarting or reconnecting helped.

Do not send hole cards, join links, QR codes, seat credentials, Wi-Fi passwords, or other secrets.

使用条件

  • 一台运行 Orbit Poker 的房主 iPhone
  • 每位客人的手机使用现代浏览器（有 iPhone 的客人也可以用 Orbit Poker App 加入）
  • 所有设备连接同一 Wi‑Fi 或房主个人热点
  • 所有玩家已满 18 岁

筹码只用于计分。产品不支持真钱下注、购买筹码、兑现、奖金或筹码转移。

创建牌桌

  1. 打开 Orbit Poker 并创建牌桌。
  2. 选择盲注、起始筹码、座位数和行动时限。
  3. 确认所有客人都在同一个局域网。
  4. 展示入座二维码；客人用系统相机扫码，在浏览器中加入。
  5. 至少两人入座后，按真实坐法排座并开始第一手。

下一手不发牌

至少要有两位有筹码、没有暂离的玩家入座，才能发下一手。两手之间，房主屏幕会显示在等什么，并给出处理按钮：

  • 筹码用完：点“补码到…”，或批准该玩家的补码申请。
  • 暂离中：等玩家回来，或请对方点“回座”。
  • 人数不足：展示入座二维码，让其他人加入。

下一手倒计时期间，房主可以点“暂停发牌”，也可以点“立即开始”。

客人打不开二维码链接

  • 确认客人与房主连接同一 Wi‑Fi 或个人热点。
  • 在房主 iPhone 打开“设置 → Orbit Poker”，允许“本地网络”。
  • 避免会隔离设备的访客 Wi‑Fi。
  • 房主切换网络后，请扫描自动生成的新二维码。
  • 让房主 App 保持在前台。

房主锁屏或切换了 App

房主 App 失去活动状态时牌桌会暂停。回到 Orbit Poker，等待客人重连后点“继续”。客人应保持浏览器页面打开。为获得最稳定的体验，建议使用闲置 iPhone 专门作为房主设备。

恢复中断的牌桌

若重新打开 App 后发现未结束牌桌，请选择“恢复上一桌”。牌桌会以暂停状态打开，等玩家重连后再继续。除非确定要永久删除当前快照，否则不要选择“放弃并删除”。

客人丢失座位

重新扫描当前入座二维码并输入原昵称。若原座位离线，房主可同意认领；若旧页面仍在线，请先关闭旧页面或换一个昵称。

删除牌桌数据

房主在 App 中结束并清空牌桌后，当前本地牌桌快照会被删除。客人也可以在浏览器中清除房主本地地址的网站数据，从而移除座位凭证。

反馈问题

请发送邮件到 elbald.fun@gmail.com，并提供房主 iPhone 型号与 iOS 版本、客人设备与浏览器版本、网络类型、出现问题的页面/手数、复现步骤和错误文字。

请勿发送底牌、加入链接、二维码、座位凭证、Wi‑Fi 密码或其它秘密信息。
