Overview

Orbit Poker is a poker table for adults playing together in person. One iPhone hosts the table, and guests join from a web browser, or from the Orbit Poker app on their own iPhone, over the same Wi-Fi network or the host’s Personal Hotspot. Orbit Poker uses play chips for scoring only; there is no real-money betting.

Orbit Poker has no user accounts, no developer-operated game servers, no advertising, no analytics, and no tracking. The developer does not receive any of the information described below.

Information handled during a table

To run the current table, Orbit Poker handles:

  • the nickname each player chooses;
  • table settings, seats, play-chip balances, cards, actions, and the current game state;
  • random table, join, and seat credentials used to let players join and reconnect;
  • local network information that devices need to talk to each other, such as local IP addresses.

This information travels only between the guests’ devices and the host iPhone over the local network. It is never sent to the developer or to any third party.

What stays on each device

Host iPhone. The app keeps one snapshot of the current table, including the result of the most recent hand, so it can recover if the app is interrupted. The snapshot is deleted when the host ends and clears the table, or chooses to discard an unfinished table. Apart from the test-build diagnostic log described below, Orbit Poker keeps no history of earlier hands or past tables. The app also remembers settings such as the interface language.

Guest browser or app. The table page may store, in local storage for the host’s local address:

  • a random seat credential, so the guest can return to the same seat after a disconnect;
  • display preferences, such as the interface language and whether the “open in app” banner or the new-player tips were turned off.

Guests can remove these by clearing the site data in their browser, or by deleting the app if they joined through it. The seat credential also stops working when the player leaves, is removed, or the table ends.

Test builds only. Development and TestFlight builds keep a local diagnostic log on the host iPhone to help find bugs, capped at about 10 MB. It records technical events such as connection changes, seat numbers, chip amounts, and timings. It never contains nicknames, cards, join links, or seat credentials. The log is kept across tables and is not cleared when a table ends; deleting the app removes it. It leaves the device only if the host chooses “Export diagnostic log” and shares the file themselves. The App Store version does not write this log.

Local network security

Devices talk over local HTTP and WebSocket connections, which are not end-to-end encrypted. Only play on a Wi-Fi network or Personal Hotspot you trust. Anyone else on the same network may be able to observe or interfere with this traffic.

The host iPhone shuffles, deals, and enforces the rules. The official app does not show other players’ hole cards to the host, but Orbit Poker cannot protect against a host device that has been modified or compromised.

Permissions

  • Local Network lets the host iPhone accept connections from guests, and lets a guest’s iPhone connect to the host, on the same network.
  • Camera is used only when you scan a table’s join QR code inside the app. The image is read on the device and is not saved or sent anywhere.

Sharing, selling, and tracking

We do not sell or share personal information, use it for advertising, or track you across other companies’ apps or websites. Orbit Poker contains no third-party advertising, analytics, or tracking SDKs.

Apple processes App Store downloads and TestFlight information under Apple’s own privacy policy. Your device and browser providers may process information under their own policies.

Children

Orbit Poker is intended only for adults aged 18 and over. It is not directed to children, and we do not knowingly collect personal information from children.

Your choices

The host can delete the current table data by ending and clearing the table; deleting the app removes everything Orbit Poker stored, including the diagnostic log in test builds. Guests can clear the stored data through their browser’s site-data settings. Because Orbit Poker has no accounts or cloud database, the developer holds no table records about you to access, correct, or delete.

Changes

We will update this policy if the product or legal requirements change, and the effective date above will show the latest version. If a future version adds accounts, cloud storage, analytics, or other data processing, we will update this policy and the App Store privacy details before that version is released.

Contact

For privacy questions, email elbald.fun@gmail.com.

Orbit Poker 隐私政策

生效日期

概述

Orbit Poker 是供年满 18 岁的玩家线下面对面使用的扑克牌桌。一台 iPhone 作为房主设备，客人在同一 Wi‑Fi 或房主个人热点中，用浏览器或自己 iPhone 上的 Orbit Poker App 加入。筹码只用于计分，不涉及真钱。

Orbit Poker 没有用户账号，没有开发者运营的游戏服务器，也没有广告、分析或追踪。下面提到的信息，开发者都不会收到。

牌局期间处理的信息

为了运行当前牌桌，Orbit Poker 会处理：

  • 玩家自己填写的昵称；
  • 牌桌设置、座位、计分筹码、牌面、行动和当前牌局状态；
  • 用于加入和断线重连的随机牌桌凭证、入座凭证和座位凭证；
  • 设备互相通信所需的局域网信息，例如局域网 IP 地址。

这些信息只在客人设备和房主 iPhone 之间通过局域网传输，不会发送给开发者或任何第三方。

各设备上保存的内容

房主 iPhone：App 保存一份当前牌桌快照（含最近一手的结果），以便 App 中断后恢复。房主结束并清空牌桌，或选择放弃未结束的牌桌时，快照会被删除。除下文所述测试版诊断日志外，App 不保存更早的手牌记录，也不保存过往牌局。App 还会记住界面语言等设置。

客人浏览器或 App：牌桌页面可能在本地存储中（按房主的局域网地址）保存：

  • 一个随机座位凭证，用于断线后回到原座位；
  • 显示偏好，例如界面语言、是否关闭了“在 App 中打开”提示条或新手提示。

客人清除浏览器中的网站数据即可删除这些内容；通过 App 加入的，删除 App 即可。玩家离桌、被移除或牌局结束后，座位凭证也会失效。

仅限测试版：开发版和 TestFlight 版会在房主 iPhone 上保留一份本地诊断日志，用于排查问题，上限约 10 MB。日志记录连接变化、座位号、筹码数额、耗时等技术事件，不包含昵称、牌面、加入链接或座位凭证。日志跨牌局保留，结束牌桌时不会清除，删除 App 即可删除。只有房主主动点“导出诊断日志”并自己分享文件时，日志才会离开设备。App Store 正式版不写这份日志。

局域网安全

设备之间通过本地 HTTP 和 WebSocket 通信，没有端到端加密。请只在你信任的 Wi‑Fi 或个人热点中使用。同一网络中的其他人可能看到或干扰这些通信。

洗牌、发牌和规则判定都由房主 iPhone 负责。官方 App 不会向房主显示其他玩家的底牌，但无法防范被修改或被攻破的房主设备。

权限

  • 本地网络：让房主 iPhone 接收同一网络中客人的连接，也让客人的 iPhone 连上房主。
  • 相机：仅在你用 App 扫描牌桌的加入二维码时使用。画面只在设备上识别，不保存，也不发送到任何地方。

共享、出售与追踪

我们不出售或共享个人信息，不用于广告，也不跨其他公司的 App 或网站追踪你。Orbit Poker 不包含任何第三方广告、分析或追踪 SDK。

Apple 按其隐私政策处理 App Store 下载和 TestFlight 相关信息；设备和浏览器提供商也可能按各自政策处理信息。

未成年人

Orbit Poker 仅面向年满 18 岁的成年人，不以儿童为对象，我们不会故意收集儿童的个人信息。

你的选择

房主结束并清空牌桌即可删除当前牌桌数据；删除 App 会清除 Orbit Poker 保存的全部内容，包括测试版的诊断日志；客人可在浏览器的网站数据设置中清除已保存的内容。Orbit Poker 没有账号和云端数据库，开发者手中没有关于你的牌局记录可供查询、更正或删除。

政策更新

产品或法律要求变化时，我们会更新本政策，页首的生效日期表示最新版本。若后续版本增加账号、云存储、分析或其他数据处理，我们会在该版本发布前同步更新本政策和 App Store 隐私披露。
